# Personal Portfolio Website

A modern and responsive personal portfolio website built to showcase my projects, technical skills, education, and developer profile.

## 🛠️ Built With

* **React.js** — Frontend library used to build the user interface
* **Vite** — Development environment and build tool
* **JavaScript** — Application logic and interactivity
* **HTML5** — Website structure
* **CSS3** — Styling and responsive design
* **Git & GitHub** — Version control and source code management
* **Vercel** — Deployment and hosting

## ⚙️ How It Was Built

The website was developed using **React.js with Vite**.

The development process included:

1. Creating a React project using Vite.
2. Designing the portfolio layout and user interface.
3. Creating reusable React components for different sections.
4. Adding personal information, skills, projects, and contact details.
5. Styling the website using CSS.
6. Making the layout responsive for different screen sizes.
7. Testing the website locally.
8. Uploading the source code to GitHub.
9. Deploying the production build using Vercel.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

### Clone the Repository

```bash
git clone https://github.com/ansh2028/bhola_portfolio.git
```

### Navigate to the Project

```bash
cd bhola_portfolio
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

The website will then be available at the local development URL shown in your terminal, usually:

```text
http://localhost:5173
```

## 🏗️ Build for Production

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🌐 Deployment

The website can be deployed using **Vercel**.

After connecting the GitHub repository to Vercel, the project can be deployed automatically whenever changes are pushed to the repository.

## 📌 Customization

To use this portfolio as your own:

1. Clone the repository.
2. Install the dependencies.
3. Replace the personal information.
4. Update the projects and skills.
5. Replace images/assets.
6. Customize the styling according to your preference.
7. Run the project locally and deploy it.
